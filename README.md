# Project Management Form

## Description

This project is developed using HTML, Bootstrap, JavaScript and JsonPowerDB.

The application allows users to:

- Save Project Details
- Update Existing Project
- Reset Form
- Search Project by Project ID

Project ID acts as the Primary Key.
